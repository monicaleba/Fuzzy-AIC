# Fuzzy-AIC
A Mamdani fuzzy inference system that classifies open-source GitHub repositories into five AI-integration taxonomy categories (DETERMINIST → AI-NATIVE) using six source-code-verifiable criteria. Validated on 196 design + 37 validation applications. Macro-F1 = 0.949 on unseen data.

This repository contains the datasets, evaluation instruments, MATLAB FIS implementation, and validation code for the AIC (AI Identification Criteria) Framework — a six-criterion weighted scoring system that determines the degree of AI integration in any open-source software application, and a Mamdani Fuzzy Inference System (FIS v6) that automates the classification.

The work is motivated by the enforcement of EU AI Act (Regulation (EU) 2024/1689), which creates binding identification obligations for AI systems. The AIC framework provides a verifiable, source-code-grounded pre-audit screening instrument deployable without relying on vendor claims or documentation.
